Your passwords,

Passel is a password manager for Linux, Windows and Android, built on the pass standard. Every entry is encrypted with your own OpenPGP key and synced through a git repository you choose. No account, no Passel server, no lock-in.

Features

Everything a password manager needs. Nothing you have to trust us with.

Encrypted with your own key

Each entry is encrypted with your OpenPGP key before it is stored or synced. Create a key in the setup wizard, or bring the one you already use.

Synced with git

Use any private repository: GitHub, GitLab, Gitea or your own server. Edits from your phone and your computer merge, and nothing is lost when the same entry changed on both.

Plain pass vaults

One encrypted file per entry, in folders. Passel, the pass command line and every other pass app read and write the same vault.

Several vaults

Personal, work, shared with your family or a team: each vault has its own remote. Switch between them from the title bar.

Entries with fields

Username, URL, notes, recovery codes or fields of your own next to the password, one-time (TOTP) codes with a countdown, and a password generator.

History

See what changed and when. Revert one entry, or roll the whole vault back to an earlier state.

Careful with secrets

Copied passwords are cleared from the clipboard and hidden from the keyboard. On Android: fingerprint or face unlock, auto-lock after two minutes, no screenshots.

Import your passwords

Coming from KeePass, KeePassXC or Buttercup? The desktop app imports your database into a new vault.

In your language

English, French, German, Spanish and Brazilian Portuguese, on every platform.

No lock-in

It's just files. Encrypted ones.

A Passel vault is a standard pass password store: a folder with one OpenPGP-encrypted file per entry, kept in git. Nothing is hidden in a proprietary database, and you can stop using Passel any day without exporting anything.

  • The git host only ever sees encrypted entries. Like pass, entry and folder names are plain file names: see the privacy policy.
  • Works offline: changes wait until the next sync.
  • The desktop app uses GnuPG; Android uses rPGP. Both open the same vault with the same key.

How it works

Up and running in three steps

  1. Get a key

    The setup wizard creates an OpenPGP key for you, or imports the key you already use with pass.

  2. Open a vault

    Start a new vault, or download an existing one from its git remote.

  3. Sync everywhere

    Install Passel on your other devices, open the same vault with the same key, and your passwords follow you.
